# Roadmap

## Next

1. **Claude Code plugin.** Slash commands (`/team-plan`, `/team-build`, `/team-ship`,
   `/team-market`) so the team can be driven from any project in the Claude app.
2. **First real projects.** Onboard a second codebase (for example a Next.js app) and fix what
   generalising from todo-py missed.
3. **Scheduled shifts.** Run `agent-team ship` on a schedule, with a lock so two shifts never
   overlap.
4. **Focused context.** Let the lead pick the relevant files for a task instead of sending the
   whole project, so large codebases stay affordable.

## Later

- Parallel builders on independent parts of one plan.
- A tool-use path for non-Anthropic devops members.
- Per-member cost reporting from provider usage.
- Discovery of remote nodes on a local network.
