# Documentation

- README: what it is in one sentence, who it's for, install, a first working example, where to go next.
- Guides are task-oriented ("Add a payment method"), with steps and the expected result of each.
- Reference docs list every option with its default and an example.
- Examples must run. Prefer copy-pasteable commands; show expected output when helpful.
- Explain why for decisions people will question.
- Keep docs next to the code they describe and update them in the same change.
- Plain words, short sentences, active voice. Define terms once.
