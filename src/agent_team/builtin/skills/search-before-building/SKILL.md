# Search before building

Before writing something new:
- Search the codebase for an existing helper, pattern or module that does it or nearly does it.
- Check the standard library and the dependencies already in use.
- Consider a well-maintained library if the problem is general and hard (parsing, crypto, dates).
- Prefer extending what exists over adding a parallel way of doing the same thing.
Say what you found and why you reused it or didn't.
