Review $ARGUMENTS for accessibility.

Check keyboard access and focus order, visible focus, accessible names, semantic structure (headings,
landmarks, lists, tables), form labels and errors, contrast, motion, and screen-reader announcements
for dynamic content. Report each finding with the WCAG criterion, where it is, and the fix.
