name: git
description: Commits and branches
---
- One logical change per commit, with a message that says why in the imperative ("Add retry to upload").
- Never commit generated files, build output, local config or secrets.
- Don't rewrite history that others may have pulled.
- Keep pull requests small enough to review in one sitting; split large work.
- Update the changelog in the same change when users would notice it.
