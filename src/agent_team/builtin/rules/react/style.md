- Function components and hooks. Keep components small; lift state only as far as needed.
- Follow the rules of hooks; list every dependency of effects and memos.
- Derive values instead of syncing them with effects.
- Every interactive element is reachable by keyboard and has an accessible name.
- Lists have stable keys (never the index when items can move).
- Test what the user sees with Testing Library queries by role and label.
